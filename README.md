# 知页 PaperBridge

Windows 文献阅读与学术写作客户端的官方下载仓库。

从 [Releases 下载 Windows x64 内测版](https://github.com/chuckieZhang/paperbridge-releases/releases)。每个版本随附 SHA256SUMS.txt 和使用说明。

此仓库仅用于发布安装包和更新清单，应用源码在独立的私有仓库维护。内测版使用独立 Ed25519 更新清单签名及安装包校验，Windows 代码签名尚未配置，安装时可能显示未知发布者。

内测版支持账号注册、登录和领取运营方分配的模型授权，也可使用自己的 API Key。文献与文档保存在本机，翻译、问答和辅助写作会把必要内容发送至用户配置的模型渠道。

旧的 `0.2.0-beta.1` 和 `0.2.0-beta.2` 需手动安装一次新版。从 `0.2.0-beta.3` 开始，可以通过“客户端设置 → 软件更新”获取后续内测版本，下载完成后点击“保存并重启安装”。
